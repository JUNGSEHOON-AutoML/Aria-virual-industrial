    03 / IMPLEMENTATION

    지금까지 구현한 것과 다음 단계

    dt-cnotta

    최신 순서: M7 → G1 → G2 → L2 → L3 → L4 → V1–V3 → M3 → M4 → G3 → M5 → M6. M3·M4·M6의 기존 Replay 구현은 새 기능을 연결한 뒤 재검증합니다.

    G1·G2·L2는 구현과 CPU 검증을 완료했습니다. L3 에이전트 작업, L4 4족 모델, G3 수치 출처 전수 검사는 다음 단계입니다.

    04 / VERIFICATION & ACCESS

    확인된 근거로 보는 현재 상태

    움직이는 공정은 이렇게 확인하세요.

    1. Live 운영을 열고 아래 Live 시작을 누릅니다. CPU 실검사 중에는 공정 시계가 대기합니다.
    2. 최근 검사 결과를 누르면 원본과 히트맵이 열립니다. 고장 주입으로 순찰·복구를 확인합니다.
    3. Replay 보기에서 9개 저장 레인과 정책 A/B 물류를 재생합니다.
    Live 운영 열기 ↗Replay 캠퍼스 ↗단일 실행 화면 ↗실제 GPU의 화풍·FPS는 미확인입니다.
    현재 안내 페이지는 3D 렌더링 없이 동작합니다.
    서버가 꺼져 있을 때 실행 명령
