05. 지연·기한·시간 계약

서비스 시간과 화면 시계, 벨트 기한을 분리

실측 프로파일

각 bank × backend에 대해 warm-up 50회 후 최소 1,000회 측정한다. pre·feat·search·post와 실제 end-to-end total을 같은 sample index에 보관한다. GPU 동기화 방식, batch, 입력 순서, 온도·메모리·실행 PID·환경을 기록한다. 캐시 구축 시간과 실제 이미지 추론 지연을 혼동하지 않는다.

모드정의
legacy_constant기존 processing_time 및 기존 로봇 동작을 유지하는 회귀 경로. P0 canonical trace와 비교.
constant_median실측 total의 중앙값 고정. 현재 benchmark의 latency_mode=constant가 이 실험 의미를 가진다. 단계별 중앙값 합이 total 중앙값과 같다고 가정하지 않는다.
profile같은 표본 index의 단계·total을 사용. total_ms/1000 + handling_s가 검사 서비스 시간. 로봇은 INSPECT 단계만 치환.
deadline_s = d / v − actuator_s
response_s = decision_time − trigger_time
deadline_met ⇔ response_s ≤ deadline_s
v_max(q) = d / (T_response,q + actuator_s)

단위는 d[m], v[m/s], 시간[s]. response에는 대기·setup·고장·추론·필요 핸들링을 포함한다. 프로파일 total만 쓰는 v_max는 대기 없는 이론적 참고 상한으로 표시한다. v≤0, d≤0 또는 유효 기한≤0은 설정 오류로 거부하는 보완 검증이 필요하다.

현재 DES의 표현 한계

현행 P2는 검사 셀 입장을 trigger로 보고 blocking-after-service를 사용한다. 기한 초과 결정을 고정해도 자원은 잔여 서비스 종료까지 점유하고 HOLD 이동은 이후에 일어난다. 연속 벨트에서 물리 위치에 맞춰 비동기 분류하는 구현으로 설명하면 안 된다. 해당 모델이 필요하면 별도 버전·검증 게이트를 둔다.

sim_time은 DES 시간, wall_ns는 프로세스의 monotonic 기록이다. replay 지연은 profile에서 읽고 wall_ns 차이로 계산하지 않는다. 같은 시드의 결정론 비교에서 wall_ns·실행 토큰은 제외한다. [S1, S5]

소스 생성

defect_rate=0.05는 assumed 생성 확률이다. 평가기가 정상/불량 풀을 만들고 seed 고정 Bernoulli로 풀을 선택한 뒤 그 안에서 균등 복원추출한다. source_schedule에는 라벨 없는 이미지 ID와 provenance를 저장한다. 관측 불량률을 강제로 5%로 맞추지 않는다. 같은 비교쌍에는 동일 스케줄과 해시를 적용한다.

가정 인간 모델

기본 1명, 서비스 30초, sensitivity=specificity=1.0. 모두 assumed이며 실제 사람의 정확도·생산성 측정치가 아니다. NG만 재검사하므로 AI FN은 기본적으로 이 경로에서 회수되지 않는다. GT 누락은 B 실행 전 오류다. seed·part·image에 묶인 RNG로 모델별 NG 집합 차이가 인간 판정 난수 순서를 바꾸지 않게 한다.

오프라인 FIFO

입구는 무제한이고 본 라인을 차단하지 않는다. 큰 유한 capacity로 근사하지 않는다. queue의 WAITING과 사람의 PROCESSING을 구분한다. 종료 WIP, 평균·최대 큐, 시작 건 대기, 완료 건 체류, 미완료 건 대기 나이를 각각 집계한다. 큐가 계속 증가하면 정상상태라고 주장하지 않는다.

GT 불변성 검증의 조건
source_schedule을 먼저 고정한 뒤 GT 컬럼 제거·변경에 AI 판정이 불변인지 확인한다. B의 인간 판정과 전체 최종 출력은 의도적으로 GT에 의존한다. GT를 바꿔 소스 스케줄까지 다시 만든 비교는 AI 누출 검사가 아니다.

HOLD와 AI 원 판정은 서로 다른 축이다. 현행 legacy SKIPPED를 HOLD로 매핑하더라도 최종 경로, timeout 사유, 늦은 결과를 별도 보존하는 보완 계약을 적용한다. [S2, S4, S5]

통계 단위와 비교

조건·클래스별 시드 KPI 30개에 t-구간(df=29)을 적용한다. 모델 간 차이는 같은 시드의 차이 d_i로 계산한다: mean(d) ± t(0.975,29) × sd(d)/√30. 이미지 재사용 횟수를 독립 표본 수로 간주하지 않는다. 고정 데이터·뱅크에서의 DES 변동 CI와 데이터 일반화 불확실성을 구분한다.

  • 짝지음은 seed 번호뿐 아니라 소스 스케줄, 고장·지연·인간 판정 RNG 분리 방식으로 검증한다. 동일 seed라도 소비 순서가 달라지면 공통 난수 보장은 아니다.
  • 클래스별 결과를 우선 보고한다. 통합 평균은 가중 방식과 해석을 미리 고정한다. null 분모 조건은 0으로 치환하지 않는다.
  • 여러 모델·속도를 비교한 CI는 동시 신뢰구간이 아니다. 우월성 검정이 필요하면 주 비교와 다중 비교 방법을 먼저 정한다.
  • 완료 건만의 대기시간에는 생존자 편향이 있으므로 종료 잔량·미완료 대기 나이를 같이 제시한다.

가설: H1은 지연 꼬리가 HOLD와 기한 여유를 바꾸는지, H2는 오판정이 회수·폐기·유출·재검사 WIP를 바꾸는지, H3는 특징 추출·로봇 이동이 검색 개선을 가리는지 검증한다. 모든 비교에서 CCIFPS의 우위를 전제하지 않는다.
